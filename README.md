# MusicFl

MusicFl es un reproductor de música local para Android y Windows.

[Descargar la última versión estable](https://github.com/JorgeBarrera117/MusicFl-Releases/releases/latest)

- **Android:** descarga el archivo APK y confirma la instalación. Si vienes del build 44 o anterior, instala el APK manualmente una vez.
- **Windows x64:** descarga y abre el instalador Setup.exe. Puedes elegir la carpeta de instalación y si estará disponible solo para ti o para todos los usuarios.
- Para buscar nuevas versiones desde MusicFl, abre **Ajustes → Acerca de MusicFl y actualizaciones**.
